# 问题一：大规模检测点条件下的算法扩展

## 1. 扩展逻辑

设检测点数为 \(n\)，每个检测点提供测向区间的两条边界，故共有 \(N=2n\) 个线性半平面约束。定位区域可表示为

\[
\Omega=\bigcap_{k=1}^{N}
\left\{\boldsymbol{x}\in\mathbb{R}^{2}:\boldsymbol{a}_k^{\mathrm T}\boldsymbol{x}\le b_k\right\}.
\]

半平面是凸集，凸集的交仍为凸集。因此，在定位区域非空、有界且非退化的有效输入下，\(\Omega\) 为凸多边形[1]。这说明本题定位区域与二维半平面交算法的求解对象完全一致，而不只是形式相似。

当检测点数量增大、直接枚举算法的 \(O(n^3)\) 计算量难以接受时，可将“枚举边界交点并检验全部约束”的顶点生成步骤替换为基于边界方向排序和双端队列维护的二维半平面交算法[2]。对 \(N\) 条边界进行方向排序需要 \(O(N\log N)\) 时间；在随后的队列维护中，每条边界至多进入和移出队列一次，计算量为 \(O(N)\)，并可得到沿凸多边形边界有序排列的 \(m\) 个顶点。再使用旋转卡壳法遍历对踵点对，可以在 \(O(m)\) 时间内求得凸多边形直径[2]。由于 \(m\le N=2n\)，扩展方案的总时间复杂度为

\[
O(N\log N+N+m)=O(n\log n).
\]

## 2. 可直接用于论文正文的表述

> 本文采用直接枚举边界交点的方法，以保证算法过程清晰且便于核验。设检测点数为 \(n\)，每个检测点产生两个线性半平面约束，故定位区域是 \(N=2n\) 个半平面的公共交集；在区域非空、有界且非退化时，其结果为凸多边形[1]。若检测点数量增大，使直接枚举算法的 \(O(n^3)\) 计算量难以接受，可采用基于边界方向排序和双端队列维护的二维半平面交算法，在 \(O(N\log N)\) 时间内获得按边界顺序排列的 \(m\) 个顶点；随后采用旋转卡壳法，以 \(O(m)\) 时间计算凸多边形直径[2]。由于 \(m\le N=2n\)，扩展方案的总时间复杂度为 \(O(n\log n)\)。该方案只替换定位区域顶点及直径的计算方法，不改变本文的半平面定位模型和圆盘覆盖判据。本文未对该扩展方案进行程序实现和运行时间测试，故仅将其作为大规模检测点条件下的理论扩展。

## 3. 论证链条

1. 每个检测点产生两个线性半平面，故本题定位区域就是有限个半平面的交。
2. 有效定位区域为凸多边形，满足二维半平面交算法的输入条件。
3. 半平面交算法直接输出有序凸多边形顶点，满足旋转卡壳法的输入条件。
4. 两种算法依次替换“生成全部顶点”和“枚举全部顶点对”两个计算环节，模型定义与最终直径指标均不改变。
5. 相关算法和复杂度来自现有中文教材；本文只作适用性与复杂度推导，不将未经实现的扩展写成实验结论。
