## 2. 已确认：题面事实

### 2.1 任务对象与信息边界

- [x] 目标区域是以原点为圆心、半径为 1800 m 的圆域，所有干扰源均位于其中。
- [x] 问题三中的干扰源全部为全向干扰源。
- [x] 干扰源总数为 10–16 个，具体数量未知。
- [x] 频道范围为 1–20；每个干扰源频道互不相同，且频道不随时间变化。
- [x] 不同干扰源的信号互不影响。
- [x] 每个干扰源的有效接收半径分别位于 1000–1500 m，具体数值不通过接口返回。
- [x] 测向误差位于 \([-1^\circ,1^\circ]\)。同一地点的环境误差固定，原地重复测同一频道不能当成独立重复测量来平均降噪。
- [x] 机器狗初始位置为 \((0,0)\)，测向机初始频道为 1。
- [x] 机器狗可以向模拟器提交目标圆域外的位置，但坐标分量必须满足接口范围要求。

### 2.2 动作与时间

- [x] 机器狗移动速度为 5 m/s，移动过程中不能有效检测。
- [x] 一次检测耗时 5 s。
- [x] 任意两个不同频道之间切换耗时 1 s；只有合法的 `/measure` 会改变测向机当前频道。
- [x] `/clear` 中的频道仅指定清除目标，不切换测向机频道，也不产生频道切换耗时。
- [x] 清除点距目标不超过 20 m 时，光学定位和清除可以成功；成功动作耗时 5 s。
- [x] 清除点周围 20 m 内没有指定频道目标时，清除失败并耗时 3 s。
- [x] 同一个干扰源只能被成功清除一次。
- [x] 题目统计的定位清除总时间包含移动、频道切换、检测、光学定位和清除等虚拟耗时。
- [x] 现实程序运行时间与虚拟任务时间是两套时间；现实程序时间受 `/enter` 后最长 20 min 和 25 min 测试窗口的共同限制，并需在正式测试结果中报告。

### 2.3 接口反馈

- [x] `direction`：检测到信号并返回带误差的示向度；此时源距检测点大于 5 m 且不超过其有效接收半径，因此不超过 1500 m。
- [x] `near`：检测点位于源的 5 m 范围内，无法获得示向度。
- [x] `no_signal`：当前位置收不到该频道信号；它不能单独证明该频道没有干扰源。
- [x] `/clear = success`：指定频道目标已经成功清除。
- [x] `/clear = no_target_in_range`：指定频道未清除目标不在该清除点的 20 m 范围内。

### 2.4 正式交付

- [x] 需要先通过模拟器进行演练测试，再进行三次正式测试。
- [x] 正式测试需要报告案例编码、清除干扰源个数、平均定位清除时间和程序运行时间。
- [x] 三次正式测试日志需要保持模拟器导出的原文件名并放入支撑材料。

## 4. 已确认：频道状态与任务完成判据

### 4.1 每个频道的状态

| 状态 | 含义 | 允许进入该状态的证据 |
|---|---|---|
| 未发现、未排除 | 尚未收到信号，也没有完成全域排除 | 初始状态，或仅有局部 `no_signal` 记录 |
| 已发现、未清除 | 已确认该频道存在干扰源，但尚未成功清除 | 曾收到 `direction` 或 `near` |
| 已清除 | 该频道目标已经成功清除 | `/clear = success` |
| 已排除 | 已有充分证据表明目标圆域中不存在该频道的未清除目标 | 该频道的无信号检测圆完成全域覆盖核验 |

- [x] “已经定位”不等于“已经清除”。能够保证清除但准备稍后顺路处理的频道，仍属于“已发现、未清除”。
- [x] 已清除或已排除的频道不再检测。
- [x] 已发现频道的综合可能区域若计算为空，必须检查记录、口径和数值实现，不能自动改为“已排除”。

### 4.2 逐频道排除证明

设目标圆域为 \(D\)，频道 \(c\) 实际返回 `no_signal` 的检测点集合为 \(M_c\)。团队确认采用以下保守充分条件：

\[
D\subseteq\bigcup_{S\in M_c}B(S,1000)
\quad\Longrightarrow\quad
c\text{ 可标为“已排除”}.
\]

- [x] 覆盖必须逐频道核验；其他频道在某位置被检测过，不能替代频道 \(c\) 在该位置的检测。
- [x] 一次或少数几个未覆盖全域的 `no_signal` 不能证明频道为空。

### 4.3 任务完成判据

满足以下任意一项，可以结束正常任务：

- [x] 20 个频道全部处于“已清除”或“已排除”状态；
- [x] 已经成功清除 16 个不同频道的干扰源，达到题面总数上限。

以下现象不能单独作为完成证据：

- [x] 已经清除 10–15 个源；
- [x] 连续多次没有发现新源；
- [x] 只完成原点全频道扫描；
- [x] 程序超时、窗口超时或手工中止。

## 5. 已确认：基础起步与频道调度

### 5.1 固定起步动作

- [x] 机器狗在原点从频道 1 开始，依次检测频道 1–20。
- [x] 原点全频道扫描的基础虚拟耗时为 \(20\times5+19\times1=119\) s，不含可能发生的清除动作。
- [x] 收到 `direction` 时记录该频道和观测，继续完成原点扫描，不立即离开原点追踪。
- [x] 收到 `near` 时，在原地对该频道立即执行 `/clear`；成功后继续扫描剩余频道。`/clear` 不改变当前测向频道。
- [x] 收到 `no_signal` 时保存该频道在原点的无信号记录，不直接判定频道为空。
- [x] 原点扫描属于团队选定的简单起步规则，不宣称它必然是最省时的起步方式。

### 5.2 到达其他位置后的频道选择

- [x] 全域搜索点默认扫描所有“未发现、未排除”的频道。
- [x] 已发现但未清除的频道，根据补测价值决定是否在该搜索点检测。
- [x] 专门补测点或清除点先完成本次到达的目标动作，再选择性检测其他频道，不固定扫描全部频道。
- [x] 对每个已发现但未清除频道，实时维护其综合可能区域的最小外接圆半径。半径不超过 20 m 时已经存在一次保证清除点；半径大于 20 m 时允许进入补测候选池，但不因此自动获得行动优先级。
- [x] 到达专门补测点后，除主要目标频道外，需要检查并额外检测具有明确用途的其他频道；移动绕路只计一次，各频道仍分别计算检测和切换时间。
- [x] “有价值的额外频道”资格规则已经确认。对已发现频道，须尚未清除、当前最小外接圆半径大于 20 m，并且在该位置至少满足一项：能够保证或可能形成具有新几何关系的方向观测；返回 `no_signal` 时其 1000 m 排除圆能删除当前综合可能区域的非空部分；本次检测能够替代该频道尚未完成的托底检测任务。
- [x] 取得上述资格只表示该频道可以进入当前位置的附加检测候选集，不表示必须检测，也不自动获得行动优先级。
- [x] 在外围托底点完成必要扫描后，可以在当前坐标原地追加检测最多 2 个有价值频道；该规则不包含前往任何专用补测点，因此不产生新增移动距离，各附加频道仍分别计入 5 s 检测和必要的频道切换时间。
- [x] 是否离开当前外围点前往另一个专用补测点，属于独立的下一目的地决策，必须计入从当前点绕行并接回后续托底路线的完整增量时间，不能混入“原地追加最多 2 个频道”的规则。
- [x] 专用补测点完成主要目标并更新状态后，也最多追加检测 2 个有价值频道；主要目标频道和必须完成的托底检测任务不占这 2 个名额。
- [x] 多个合格额外频道采用分级排序，不设置未经依据的加权总分：先看是否能够减少或替代未来托底任务，再优先保证接收且交会几何较好的频道，随后考虑 `no_signal` 能排除当前可能区域比例较大的频道。
- [x] 同一优先级内，依次参考交会几何指标、1000 m圆与当前可能区域的交集比例、最小外接圆半径；仍相同时优先当前频道，最后按频道编号固定排序，保证可复现。
- [x] 上述排序只决定最多 2 个名额给谁，不表示被选频道的信息收益已经得到精确时间证明。
- [x] 可选额外频道采用 **6 s 最低净收益阈值**。对频道 \(c\) 在当前位置 \(P\)，用
  \[
  \widehat V_c(P)=\widehat C_c^{\mathrm{before}}-\left[\Delta t_c(P)+\widehat C_c^{\mathrm{after}}(P)\right]
  \]
  粗略衡量附加检测是否值得，其中 \(\Delta t_c(P)\) 按真实检测顺序计入 5 s 检测时间和必要的 1 s 换频道时间；只有 \(\widehat V_c(P)\ge 6\text{ s}\) 时，该频道才可占用“最多 2 个额外频道”的名额。
- [x] 上述阈值只约束可选的顺带检测，不适用于必须完成的托底频道、专项补测的主要目标频道以及触发 `near` 后的立即清除。6 s 属于团队设定，后续采用 0 s、6 s、12 s 做敏感性检查。
- [x] 若某频道在候选位置不可能收到信号，且该点的 1000 m 排除圆与其综合可能区域也没有有效交集，则不把该频道列为附加检测对象。
- [x] 当前测向频道若在待测列表中，优先检测该频道；其余频道采用固定顺序即可。任意跨频道切换时间均为 1 s，不根据频道编号距离排序。
- [x] 若后续行动明确需要某频道，可以将它安排为当前位置最后一个检测频道，以减少下一阶段切换。

## 6. 已确认：补测点、顺路检测与移动计价

### 6.1 补测点来源

- [x] 同时考虑为当前定位区域专门生成的补测点，以及机器狗已经计划经过或到达的位置。
- [x] 第二问结果可以提供补测候选，不直接规定机器狗必须前往其单源最优点。
- [x] 已有多次观测后，补测点价值应基于全部已有观测判断，不能只套用最初的一次示向度。
- [x] 选择下一个位置时优先考虑能兼顾多个频道或搜索任务的位置，但不要求每次移动必须服务多个目标。

### 6.2 顺路补测的新增耗时

原计划从 \(P\) 直接前往 \(Q\)，现改为在 \(S\) 停下补测后继续前往 \(Q\)，则相对原计划的新增时间为

\[
\Delta T
=\frac{\|P-S\|+\|S-Q\|-\|P-Q\|}{5}
+5+\Delta T_{\mathrm{频道切换}}.
\]

- [x] 若 \(S\) 位于线段 \(PQ\) 上，新增移动时间为 0，但检测和必要的频道切换仍需计时。
- [x] 频道切换成本要比较插入检测前后整段行动的变化，不能只计算切到补测频道的一次切换。
- [x] 移动过程中不能检测；所谓“途中补测”是预先决定在明确位置停下并调用 `/measure`。
- [x] 每次获得反馈后允许重新安排后续行动；实际总时间按真正执行的动作累计。

### 6.3 “一点多用”的统一含义

“一点多用”指机器狗移动到一个位置后，在该处推进多个任务，例如为多个已发现频道补测、为未知频道增加搜索覆盖证据，或处理附近可清除目标。每个检测和清除动作仍分别计时；主要节省的是重复前往不同位置的移动时间。

### 6.4 外围托底点附近的处理机会

- [x] 机器狗到达某个外围托底点时，必须重新检查附近已发现但未清除的干扰源，而不能只执行未知频道扫描后立即离开。
- [x] 即使某频道的综合可能区域不能被一个 20 m 圆覆盖，也要比较立即补测、立即安排若干清除点与推迟处理的完整耗时。
- [x] 若继续沿托底路线前进会显著增加未来返回该区域的路线代价，则把该频道临时提升为高优先级；这种提升来自“当前位置的机会价值”，不表示该频道永久优先。
- [x] 最小外接圆半径只用于判断是否存在一次保证清除，不作为是否立即处理该频道的唯一门槛。
- [x] “附近”优先根据综合可能区域到当前点或当前路线段的最短距离判断，不能只看区域中心或最小外接圆圆心。
- [x] 当前处理与推迟处理的比较必须计入绕路、检测、换频道、清除以及处理后接回剩余托底路线的时间。

### 6.5 补测反馈未知时的分支评价

- [x] 决定是否前往候选补测点前，不把补测后的定位区域或清除点数量写成一个确定结果，而是分别考虑该点可能返回的 `near`、`direction` 和 `no_signal` 分支；只评价与当前综合可能区域相容的反馈。
- [x] `near` 分支按原地立即清除评价；`direction` 分支用新示向角域更新综合可能区域后重新生成清除方案；`no_signal` 分支删除候选点周围 1000 m 圆后重新生成清除方案。
- [x] 对每个可行反馈分支，计入前往补测点、频道切换、5 s检测、该分支后续定位或清除，以及接回下一托底任务的完整时间，记为 \(Q(P,o)\)。
- [x] 题面没有给出反馈概率分布，因此不擅自计算人为期望时间。令

  \[
  Q_{\mathrm{best}}(P)=\min_o Q(P,o),\qquad
  Q_{\mathrm{worst}}(P)=\max_o Q(P,o).
  \]

  并与不补测、直接完成当前清除任务的时间 \(C_{\mathrm{direct}}\) 比较。
- [x] 若 \(Q_{\mathrm{worst}}(P)<C_{\mathrm{direct}}\)，则补测属于强接受；若 \(Q_{\mathrm{best}}(P)\ge C_{\mathrm{direct}}\)，则属于强拒绝；其余情况归入灰色区间。
- [x] 灰色区间内根据补测是否原地或顺路、能否同时服务多个频道、以及错过当前位置后可能增加的返程代价决定，不把任何单一有利分支当成确定收益。
- [x] 补测前可以对可能示向度使用少量代表值或边界值作候选排序，但必须标明这是近似代理；实际收到反馈后必须重新计算综合可能区域和清除方案，最终完成或清除保证不能依赖补测前的抽样预测。

### 6.6 专用补测点的少量候选与粗评价

- [x] 第三问不在每次决策时重复运行第二问式的大规模连续搜索。对每个待处理频道只保留 5～10 个去重后的补测候选；候选不足时不强行凑数。
- [x] 候选点由三类来源组成：当前点、下一相邻外围点及现有路线上的复用点；距离当前计划路线较近的保证接收点；第二问模块提供的少量左右侧或不同绕行水平的几何较优点。
- [x] 对需要专门绕路前往的补测点，原则上要求保证接收；原本就会经过或新增绕路很小的点可以保留B档候选，因为 `no_signal` 仍可能提供排除信息。
- [x] 同一频道已经在同一坐标获得过示向度时，不把原地重复测向作为新的定位候选；同一地点误差固定，重复测向不能平均减小误差。
- [x] 每个候选只使用少量代表源位置进行粗评价。代表位置应覆盖当前综合可能区域的距离极端、角域边界、主要顶点和各个不连通部分；第二次测角误差至少取 \(-1^\circ,0^\circ,1^\circ\)。
- [x] 粗评价所得最大值记为“代表情景最大值”或 \(\widehat Q_{\max}\)，只用于候选排序，不称为连续源位置与连续误差上的严格最坏值。
- [x] 对代表情景预测补测后的综合区域：若最小外接圆半径不超过 20 m，则估算“前往补测—检测—前往清除—成功清除—接回托底路线”的完整时间；否则用较粗的方格覆盖估算清除圆数量、候选清除路线和接回时间。
- [x] 候选的主要排序指标始终是代表情景下的完整完成时间；最小外接圆半径只承担一次清除初筛、结果解释和同级候选辅助比较，不单独决定下一目的地。
- [x] 将较优补测候选的代表情景最大完成时间与当前直接清除方案比较；差异很小时优先顺路或能够服务多个频道的候选，明显绕路且无时间优势时不为追求更小定位区域而强行补测。
- [x] 候选点允许位于目标圆外，但必须满足接口坐标范围，并把前往该点及接回后续托底路线的移动时间完整计入。
- [x] 实际获得反馈后，丢弃补测前的预测区域，依据真实反馈重新构造保守综合可能区域；实际清除前仍须进行一次或多圆的连续覆盖核验。粗评价误差只允许影响效率，不得承担清除完成证明。

### 6.7 一次清除、多点清除与继续补测的局部闭环

- [x] 若当前综合可能区域的最小外接圆半径不超过 20 m，则把该频道登记为“单点可清除”，不再为其生成专用补测任务；何时执行该清除仍由位置和后续路线决定。
- [x] 若最小外接圆半径大于 20 m，先用经覆盖核验的方格清除点及候选访问顺序构造直接多点清除基线，记其完整完成并接回托底路线的时间为 \(C_{\mathrm{multi}}\)。
- [x] 允许把最小外接圆圆心作为一次“试清除”候选，但不采用固定的 25 m 半径阈值，也不把它表述为保证成功。分别计算成功分支和失败后删除该点周围 20 m 圆、重新覆盖清除的分支。
- [x] 试清除以成功、失败两分支中的较大完整时间评价；仅当其相对直接多点清除具有时间优势，或处于低绕行的位置机会时，才进入行动候选。
- [x] 对 5～10 个补测候选取代表情景最大完成时间中的较小值，记为 \(\widehat Q_{\mathrm{measure}}\)，并与 \(C_{\mathrm{multi}}\) 比较。两者证据强度不同：前者是排序代理，后者是经覆盖核验的可行完成基线。
- [x] 采用一次“换频道＋检测”的 6 s 作为局部收益缓冲：若 \(\widehat Q_{\mathrm{measure}}\le C_{\mathrm{multi}}-6\)，优先补测；若 \(\widehat Q_{\mathrm{measure}}\ge C_{\mathrm{multi}}+6\)，优先直接多点清除。
- [x] 当两者差异小于 6 s 时进入灰色区间：补测位于当前点或现有路线、能够服务多个频道时倾向补测；需要专项绕路时倾向采用已验证的多点清除；正处于位置机会窗口时还要考虑错过后的返程代价。
- [x] 6 s 是为了避免近似评价微小波动改变行动而采用的团队简化参数，不是题面事实；后续只需用 \(0,6,12\) s 等少量取值检查主要选择是否敏感。
- [x] 每次真实检测或清除反馈后，更新综合可能区域并重新进入本局部闭环，不沿用反馈前预测的清除点数量或行动排序。

### 6.8 防止反复补测的停止与强制清除规则

- [x] 区分专项补测与顺路原地补测。若某位置原本不在托底或其他既有任务中，频道 \(c\) 是插入该位置的原因之一，则记为该频道的一次专项补测；机器狗原本就会到达该位置时的附加检测属于顺路补测。
- [x] 每个频道最多执行 2 次专项补测，首次发现该频道的测向不计入该上限；同一补测点同时服务多个频道时，对每个将该点作为专项任务原因的频道分别计数。
- [x] 顺路补测不计入 2 次专项补测上限，但仍计入检测和切换时间；同一频道不得在同一坐标重复测向。
- [x] 补测前后分别计算保证多点清除时间 \(C_{\mathrm{multi}}^{\mathrm{before}}\)、\(C_{\mathrm{multi}}^{\mathrm{after}}\) 和所需清除圆数量 \(m^{\mathrm{before}}\)、\(m^{\mathrm{after}}\)。
- [x] 一次补测满足以下任意一项即记为明显收益：形成最小外接圆半径不超过 20 m 的单点可清除状态；使保证清除圆数量减少；使保证清除完整时间至少减少 6 s。三项均不满足则记为低收益补测。
- [x] 为每个频道维护连续低收益次数；出现明显收益时清零，出现低收益时加 1。连续 2 次低收益时停止为该频道购买新的补测信息。
- [x] 顺路补测虽然不占专项次数，但计入连续低收益判断，防止用“顺路”名义无限延迟清除。
- [x] 满足以下任意条件时，频道进入 `CLEAR_COMMITTED` 强制清除状态：专项补测达到 2 次；连续 2 次低收益；不存在满足当前 6 s 比较规则的补测候选。
- [x] `CLEAR_COMMITTED` 表示该频道的后续解决方式固定为已经验证的单点或多点清除序列；不再生成专项补测，也不再占用驻留点的可选额外检测名额。它不等于必须立刻离开所有任务冲向目标，具体插入总体路线的时机仍待全局统筹。
- [x] 强制清除过程中若清除失败，删除对应 20 m 圆并重新覆盖、重排剩余清除点，但频道仍保持 `CLEAR_COMMITTED`，不切回补测状态；清除成功后转为已清除。
- [x] 专项补测上限 2 和连续低收益上限 2 均为团队简化参数，不是题面事实；后续分别用 \(1,2,3\) 等少量取值检查主要结论是否敏感。

### 6.9 相邻托底点之间的专项宏任务插入与跳点规则

- [x] 机器狗在当前外围点 \(A\) 时，默认下一目的地为既定方向上的相邻未完成外围点 \(N\)；直接前往并执行 \(N\) 的必要托底检测构成局部比较基线。
- [x] 每次只保留三类下一行动候选：直接前往 \(N\)、当前评价最好的一个专项补测宏任务、当前评价最好的一个清除宏任务，避免同时展开所有频道和所有坐标。
- [x] 对专项点或专项任务 \(Q\)，比较直接方案与“\(A\to Q\to N\)”方案的完整时间，计入移动、检测、切换或清除动作，以及执行前后该频道剩余完成时间的变化。
- [x] 专项方案相对直接方案至少节省 6 s 时优先插入；至少多耗 6 s 时优先前往 \(N\)；差异不足 6 s 时，根据是否顺路、能否服务多个频道和是否处于位置机会窗口决定。
- [x] 从一个外围点到下一相邻外围点之间最多插入 1 个非托底宏任务。一个宏任务可以包含一个专用补测点的多频道检测，也可以包含同一频道的一整组多点清除坐标；多点清除内部的多个坐标不分别占用插入名额。
- [x] 当前点返回 `near` 后的立即清除不受宏任务插入上限限制。
- [x] 完成插入的宏任务后，原则上接回原定相邻外围点 \(N\) 并重新规划，防止连续追逐局部任务而脱离托底骨架。
- [x] 只有满足任务成功判据，或对每个仍未发现、未排除频道都已证明其现有 `no_signal` 圆完整覆盖 \(N\) 的责任区 \(Z_N\) 时，才允许永久跳过 \(N\)。覆盖替代必须逐频道核验。
- [x] 若 \(N\) 仍有任何必要责任区任务，则只能暂时推迟，不能从剩余任务表中删除；`near`、附近的 `CLEAR_COMMITTED` 位置机会或至少节省 6 s 的专项宏任务可以构成临时推迟理由。
- [x] `CLEAR_COMMITTED` 不自动压过所有托底任务；只有当前处理相对继续前往 \(N\) 具有时间优势或明显位置机会时，才提升为当前优先行动。其清除任务仍必须保留，不能无限推迟。
- [x] “每段最多 1 个宏任务”和 6 s 插入缓冲均为团队简化参数，后续只作少量敏感性检查，不宣称形成严格全局最短路线。

## 7. 已确认：搜索安排与后备闭环

### 7.1 未知频道的搜索安排

- [x] 基础托底暂定采用 7 个检测坐标：原点和半径 1150 m 圆周上的 6 个正六边形顶点：

  \[
  (0,0),\quad
  (1150,0),\quad
  (575,575\sqrt3),\quad
  (-575,575\sqrt3),
  \]

  \[
  (-1150,0),\quad
  (-575,-575\sqrt3),\quad
  (575,-575\sqrt3).
  \]

- [x] 上述 7 点的 1000 m 圆盘能够覆盖整个半径 1800 m 的目标圆域。目标边界上距最近外围点最远的位置距离约为 988.51 m，具有约 11.49 m 的覆盖余量。1150 m 是当前暂定口径，后续若修改必须重新核验覆盖与路线时间。
- [x] 强制包含原点时，7 个检测坐标是严格最少数量：原点圆盘不接触目标边界，其余每个 1000 m 圆盘在目标圆周上最多覆盖约 \(67.498^\circ\)；仅用 5 个外围圆盘最多覆盖约 \(337.49^\circ<360^\circ\)。
- [x] 不取消原点扫描以尝试减少检测点数量。已知六圆最优覆盖数值表明 6 个半径 1000 m 圆盘仍不足以覆盖半径 1800 m 圆域，而且原点是无需移动即可利用的检测位置。
- [x] 7 点方案是保证搜索完成的托底安排，不要求每局机械地访问全部 7 点。若提前满足任务成功判据，立即结束；若途中其他检测点形成同等的逐频道覆盖证据，可以替代相应托底任务。
- [x] 搜索和已发现目标的定位、清除允许交织执行；不要求先找齐全部源，也不要求发现一个源后立即追踪到底。
- [x] 途中产生的逐频道无信号记录，经覆盖核验后可以替代原后备安排中的相应搜索任务。
- [x] 插入定位或清除动作后，必须保留各频道尚未完成的搜索记录，不能遗忘剩余区域。
- [x] 策略必须保留最终完成未解决频道排查的路径，不能无限推迟全域搜索。
- [x] 程序维护“托底检测点 × 未发现且未排除频道”的剩余搜索任务。某频道被发现后转入定位清除任务；未满足成功判据时，继续完成无法被其他证据替代的剩余托底任务。
- [x] 原点扫描没有发现任何干扰源时，固定先前往 \((1150,0)\)，之后默认沿相邻外围点依次访问；顺时针或逆时针采用固定规则，以保证方案可复现。
- [x] 后续外围托底移动默认选择相邻未完成点，不预先锁死整局路线。
- [x] 原点已获得一个或多个示向度时，对六个外围点按其对已发现频道的补测作用分为 A/B/C 三档，并据此选择第一个外围点。对频道 \(c\) 的当前综合可能区域 \(K_c\) 和外围点 \(P\)：
  - A档：\(K_c\subseteq B(P,1000)\)，在该点保证能够再次接收该频道；
  - B档：\(K_c\cap B(P,1000)\ne\varnothing\)，但不满足A档；收到方向可以增加示向信息，收到 `no_signal` 至少可以排除该交集；
  - C档：1000 m圆与 \(K_c\) 无交集，且现有信息也不能保证在该点接收；该点对该频道的确定性补测价值较低，但仍可承担原有托底搜索任务。
- [x] 第一个外围点采用字典序选择：先最大化其能够服务的A档频道数，再最大化B档频道数；仍相同时，优先选择与已有示向方向不过于平行、能够形成较好交会几何的点；再次相同时按固定外围点顺序选择，保证可复现。
- [x] “移动方向与第一次示向方向更接近垂直”只作为交会几何的简化排序指标，不作为定位精度或一次清除保证；后续若调用第二问模块，可以用综合可能区域的最坏定位评价替代该代理。
- [x] 跳过相邻点、跨越到非相邻点或插入专项补测/清除行动，按照第6.9节的完整增量时间、位置机会、逐频道覆盖替代和每段最多一个宏任务规则处理。

### 7.2 七个最近点责任分区

设目标圆域为

\[
\mathcal D=\{X\in\mathbb R^2:\|X\|\le1800\},
\]

七个托底检测点为 \(S_0=(0,0)\) 及半径 1150 m 正六边形的六个顶点 \(S_1,\ldots,S_6\)。对应责任区定义为

\[
Z_i=\left\{X\in\mathcal D:
\|X-S_i\|\le\|X-S_j\|,\ \forall j=0,1,\ldots,6
\right\}.
\]

等距边界上的点可以按固定规则划给任一相邻责任区，不影响覆盖结论。

- [x] 中央责任区 \(Z_0\) 是以内切圆半径 575 m 构成的正六边形，其顶点到原点距离约为 663.95 m，因此完全位于原点的 1000 m 检测圆内。
- [x] 六个外围责任区分别位于中心方向 \(0^\circ,60^\circ,120^\circ,180^\circ,240^\circ,300^\circ\) 的扇形范围内，由中央六边形边界、相邻分区射线和目标圆弧共同围成。
- [x] 每个外围责任区到其负责检测点的最远距离约为 988.51 m，小于 1000 m；因此每个责任区都被对应托底点的 1000 m 检测圆完整覆盖。
- [x] 责任分区用于逐频道搜索闭环、剩余托底任务登记、顺路检测替代核验，以及识别当前位置附近的补测或清除机会。
- [x] 责任分区不表示干扰源真实归属于某一区域。若频道 \(c\) 的综合可能区域 \(K_c\) 跨越多个责任区，必须保留所有非空交集 \(K_c\cap Z_i\)。
- [x] 责任分区不替代示向度、`no_signal` 和清除反馈形成的综合可能区域，不替代 20 m 清除覆盖证明。
- [x] 责任分区不规定必须逐区清空，也不禁止跨区行动。补测、清除或一点多用能够减少完成时间时，允许离开当前责任区，之后继续维护尚未完成的托底任务。
- [x] 分区首先用于降低任务管理复杂度；其是否减少总任务时间仍属于待验证结果，不能预先写成必然优势。

### 7.3 已发现频道的清除后备安排

- [x] 对迟迟无法完成的已发现频道，保留一组经过覆盖核验的有限清除点和有效访问顺序，必要时依次执行，成功即停止。
- [x] 多点清除的基础构造采用保守方格近似：先以小方格外包综合可能区域，再生成若干 20 m 清除圆，使每个被保留方格均被某个清除圆完整覆盖，最后复核连续外包区域没有遗漏。
- [x] 方格被某个清除圆覆盖，必须检查整个方格而非只检查中心；可以用方格四个顶点全部位于圆内，或使用等价的保守距离判据。
- [x] 多点清除路线以机器狗当前位置 \(P\) 为起点、当前计划接回的下一外围托底点 \(N\) 为暂定终点；“由远到近”中的远近以清除点到 \(N\) 的距离为主要参照，使候选路线逐步接近后续托底任务。
- [x] 不把由远到近固定为唯一顺序。对同一组清除点至少生成三种候选：按到 \(N\) 距离由远到近、其反向顺序、从 \(P\) 出发的简单近邻顺序。
- [x] 对候选顺序 \(\pi\)，若前 \(k-1\) 次失败、第 \(k\) 次成功，则计入从 \(P\) 访问前 \(k\) 个清除点、失败动作 \(3(k-1)\) s、成功动作 5 s，以及从成功点接回 \(N\) 的移动时间；以所有可能成功位置中的最大完成时间评价该顺序。
- [x] 三种候选中选择上述最坏完成时间较小者；该比较是可解释的简化规则，不宣称得到严格最短清除路线。
- [x] 清除失败后保存排除信息，不在同一位置对同一频道重复清除。
- [x] 每次清除失败后，将对应清除点周围 20 m 圆从综合可能区域中删除，重新检查剩余清除圆是否仍有必要，并对剩余点重新生成和比较候选顺序，不机械执行原排列。
- [x] 补测没有明显改善或候选计算过慢时，允许停止继续优化局部选择，转用清除后备安排。
- [x] “有限步能够完成”不等于“能够在模拟器限时内完成”；后备搜索和清除安排都必须另行核验时间可行性。

## 8. 已确认：允许的简化与必须准确的部分

### 8.1 行动选择允许近似

- [x] 可以只生成少量候选检测点和清除点。
- [x] 可以使用粗略时间估计、经验阈值和规则排序选择下一行动。
- [x] 不要求求出最少的 20 m 覆盖圆数量；找到一组经核验确实覆盖可能区域的点即可。

### 10.3 多频道全局统筹

- [x] 规划估计 \(\widehat H(S)\) 中已发现频道 \(c\) 的“立即直接清除”部分，统一采用相对于当前托底路线的增量完成时间计价。设当前位置为 \(P\)、原定下一托底点为 \(N\)，对一组已通过完整覆盖核验的清除点及候选顺序 \(\pi\)，扣除原本 \(P\to N\) 的移动时间，只计入插入清除序列所增加的移动时间、清除失败时间、最终成功时间和成功后接回 \(N\) 的移动时间。
- [x] 若在顺序 \(\pi\) 下前 \(k-1\) 次失败、第 \(k\) 次成功，则该分支的清除动作时间为 \(3(k-1)+5\) s；以所有与当前综合可能区域相容的成功位置中的最大完成时间评价该顺序，再在第7.3节规定的候选顺序中取较小者，记为 \(C_c^{\mathrm{direct}}(S)\)。该数值是可执行的保守完成时间估计，不称为严格最优值。
- [x] 实际执行时一旦清除成功，立即取消该频道剩余清除点；若清除失败，则删除该清除点周围 20 m 圆，重新生成剩余覆盖与顺序。由此，保守估价用于行动比较，真实反馈用于滚动修正。
- [x] 对频道 \(c\) 的补测候选点 \(X\)，补测前段固定时间为
  \[
  T_{\mathrm{front}}(P,X,c)=\frac{d(P,X)}5+T_{\mathrm{switch}}(c)+5.
  \]
  对每个相容反馈 \(o\in\{\mathrm{near},\mathrm{direction},\mathrm{no\_signal}\}\)，评价阶段按该反馈规则预测更新综合可能区域，并估计从 \(X\) 出发直接清除该频道后接回 \(N\) 的时间 \(C_{c,o}^{\mathrm{post}}(X,N)\)。相对于原路线的补测—清除增量时间为
  \[
  \Delta C_c^{\mathrm{measure}}(X,o)
  =T_{\mathrm{front}}(P,X,c)+C_{c,o}^{\mathrm{post}}(X,N)-\frac{d(P,N)}5.
  \]
- [x] near 分支在 \(X\) 原地成功清除并计 5 s；direction 分支用新角域更新后生成保证清除方案；no_signal 分支删除 \(B(X,1000)\) 后生成保证清除方案。对于已经由 direction 或 near 确认存在的频道，更新后区域若为空必须触发状态与数值核查，不能把后续清除时间记为零或把频道改成“已排除”。候选粗评价只允许“一次补测后转入直接清除”以避免递归估价；真实反馈后仍可按已确认规则滚动重规划。
- [x] 对补测候选保留相容反馈的代表情景区间，并使用代表情景最大增量时间排序；从5～10个候选中取较小者形成 \(\widehat C_c^{\mathrm{measure}}(S)\)。它与 \(C_c^{\mathrm{direct}}(S)\) 按第6.5、6.7节的强接受、强拒绝、灰色区间和6 s缓冲规则比较，不称为连续反馈空间上的严格最坏值。
- [x] 全局评价采用双层时间账本。规划层 \(\widehat H(S)\) 是从当前状态出发，按照剩余托底骨架、少量补测候选和保证清除候选构造若干可执行宏任务序列后得到的较小估计时间；安全层 \(U_{\mathrm{safe}}(S)\) 则放弃继续购买信息，采用剩余逐频道托底搜索和已核验清除后备序列得到的保守完成时间。前者决定效率排序，后者承担后备可完成性检查。
- [x] \(\widehat H(S)\) 不是全局最优价值函数，也不承担完成证明。候选序列必须按真实事件顺序逐段模拟移动、换频道、检测、清除和状态更新，同一段共享移动只计一次；不再采用“托底路线时间加各频道独立时间”的简单求和，以免重复计算共用路程。
- [x] 对行动 \(a\) 及相容结果 \(o\)，信息或完成价值统一换算为
  \[
  V(S,a,o)=\widehat H(S)-\left[t(S,a)+\widehat H(S_{a,o})\right].
  \]
  没有反馈概率时保留 \(\min_o V\) 与 \(\max_o V\)，不另设面积权重、信息权重或紧迫性权重。当前位置机会价值用“现在插入处理”与“经过下一托底点后再处理”的增量时间差表达；直接完成价值体现为对应频道任务从后续计划中消失。
- [x] 统一任务池只保留五类宏任务：强制执行的 near 原地清除；默认下一托底点及其必要扫描；每个已发现频道的保证清除宏任务；每个允许补测频道的最佳一个专项补测宏任务；进入安全模式后的后备宏任务。每次决策只比较默认托底、当前最佳补测和当前最佳清除，near 与安全强制任务优先，不同时展开全部频道与全部坐标。
- [x] 下一目的地采用“可行性优先、完整时间比较、规则化平局”的顺序：先剔除不能保持安全后备或违反补测上限的候选；再比较执行候选并滚动接回托底路线后的 \(\widehat H\)；相对默认托底方案至少节省6 s时插入，至少多耗6 s时不插入；灰色区间依次优先顺路、能够服务更多已登记任务、正处于最近位置机会的方案，最后按任务类型、频道号和坐标固定排序。
- [x] 为防止“一点多用”导致单独目标长期饥饿，每个已发现未清除频道维护等待段数：每完成一段外围托底移动而该频道没有新增有效观测、清除失败排除或成功清除，等待段数加1；取得上述进展时清零。等待2段后进入高优先级，等待3段或进入 CLEAR_COMMITTED 后，占用下一次允许插入的宏任务位置并执行保证清除；多个强制频道按等待段数、进入强制状态时间和频道号排序。2段与3段是团队初始参数，验证时至少与“1段/2段”和“3段/4段”作小规模敏感性比较。
- [x] 已经能够保证清除但距离较远的频道不因定位区域小而立即远距离追赶。满足以下任一条件时执行：现在处理相对推迟至少节省6 s；当前路线即将经过其最近位置机会且错过后返程代价上升；达到上述等待或强制清除条件；剩余托底搜索已经完成。托底搜索结束后，对所有剩余已发现频道按“从当前位置插入并完成”的增量时间滚动选择下一个。
- [x] 频道切换不与空间距离混成加权分数，而是在每条候选动作序列中按真实频道状态精确累计：同频道不计切换，不同频道计1 s；当前位置先处理当前频道，若后续任务频道已知，则尽量把它放在本位置检测序列末尾。最终仍按完整秒数比较候选。

### 10.4 后备安排与限时

- [x] 不发生提前结束、任务替代和专项绕行时，七点托底搜索最多执行140次检测。若每个点均按同一固定频道顺序扫描，频道切换不超过139次；原点至首个外围点及随后5条相邻边的总移动距离为 \(6\times1150=6900\) m。因此纯搜索骨架的保守虚拟时间上界为
  \[
  U_{\mathrm{survey}}=\frac{6900}{5}+140\times5+139=2219\ \mathrm{s}.
  \]
  该数值不含已发现源的补测与清除；实际发生提前发现、逐频道排除或达到16个清除上限时应重新计算剩余上界。
- [x] 对当前已经发现的频道，停止继续补测后，将各频道经完整覆盖核验的有限清除序列依次接入当前路线。若频道 \(c\) 的序列含 \(m_c\) 个清除点，则其清除动作最坏不超过 \(3(m_c-1)+5\) s，移动时间按实际串联路线逐段计算。把所有未清除频道依次加入并在每次反馈后更新，得到状态相关的 \(U_{\mathrm{clear}}(S)\)；它必须由程序输出具体数值，当前题意阶段不虚构统一常数。
- [x] 安全层的完整形式写成
  \[
  U_{\mathrm{safe}}(S)=U_{\mathrm{survey}}(S)+U_{\mathrm{clear}}(S)+U_{\mathrm{future}}(S).
  \]
  其中 \(U_{\mathrm{future}}\) 是对尚未发现但以后可能发现的源预留的清除上界；严格的先验有限上界可按“剩余源数不超过 \(16-n_{\mathrm{clear}}-n_{\mathrm{active}}\)，每个未来发现的源最坏使用目标圆全域的20 m覆盖后备”构造。该值通常很宽松，只承担理论有限性与风险检查；实际运行中每发现一个新频道，就用其真实观测区域替换相应预留并滚动收紧。若未计算 \(U_{\mathrm{future}}\)，\(U_{\mathrm{survey}}+U_{\mathrm{clear}}\) 只能称为当前已登记工作量，不能称为完整任务上界。
- [x] 专项补测达到 2 次、连续 2 次低收益或不存在合格补测候选时，频道进入 `CLEAR_COMMITTED` 并停止切回补测。
- [x] 现实程序限时采用预测触发的安全收尾。演练中统计单次接口往返和一次重规划的保守耗时，估计剩余后备动作现实时间 \(\widehat R_{\mathrm{real}}(S)\)；当 `/enter` 后已用时间达到15 min，或
  \[
  t_{\mathrm{used}}+1.5\,\widehat R_{\mathrm{real}}(S)\ge18\ \mathrm{min},
  \]
  任一条件成立即进入安全模式：停止产生新的专项补测和大规模候选搜索，只执行已缓存托底任务、near 清除和经核验清除后备，并保持逐动作日志。15 min、1.5倍和18 min均为团队初始参数，正式测试前必须用演练时延校准。
- [x] 到18 min仍未完成时进入紧急模式：不再做任何非必要优化，只按最少接口调用的现有安全后备继续执行；不得把超时或主动退出记为任务完成。若演练表明该规则仍不能在20 min内闭环，属于高风险实现缺陷，必须回退简化候选计算或提前触发，禁止直接进入正式测试。

### 10.5 验证与正式测试

- [x] 基础策略采用三层最低验证包。第一层是可手算或小规模穷举的动作与几何测试，覆盖5、20、1000、1500、1800 m边界，三类检测反馈、清除成败、空集/无界/不连通区域、重复坐标和频道切换。第二层是针对10个源、16个源、边界源、极端接收半径和极端测角误差的人工构造完整案例。第三层是固定随机种子的离线模拟：至少30例用于调试，冻结参数后另用30例独立评价，评价集不得反向调参。
- [x] 最低对照方案采用“固定七点逐频道托底搜索＋发现后直接执行经核验多点清除”，不使用专项补测、一点多用和动态插入；主体策略与对照必须在同一批案例上比较。主体策略只有在清除比例不下降、完成证据全部通过且虚拟总时间具有稳定优势时才保留；若独立评价的两个15例子集方向不一致，则只报告结果不宣称稳定改进。
- [x] 验证停止条件为：全部手算/边界测试通过；独立30例均满足任务完成判据、无状态或覆盖违规、无现实超时；0、6、12 s收益阈值以及2.5、5、10 m核验尺度的代表性敏感性检查不改变主要安全结论；继续增加实验不会改变基础策略取舍或主要风险判断。任一完成性失败都优先修复，不以平均时间较好抵消。
- [x] 每局统一记录：真实源数 \(n_{\mathrm{true}}\)（仅在演练真值公布后填写）、成功清除数 \(n_{\mathrm{clear}}\)、清除比例 \(n_{\mathrm{clear}}/n_{\mathrm{true}}\)、接口返回或逐动作复算的虚拟总时间 \(T_{\mathrm{virtual}}\)、平均定位清除时间 \(T_{\mathrm{virtual}}/n_{\mathrm{clear}}\)、从 `/enter` 成功至完成或退出的单调时钟现实程序时间，以及移动距离、检测数、切换数、清除成功/失败数和异常数。若模拟器提供同名官方指标，以官方值为报告依据，并与本地复算值核对差异。
- [x] 结束证据按频道保存。已清除频道必须对应唯一的 `/clear=success` 事件；已排除频道必须保存该频道全部 `no_signal` 圆和全域覆盖核验结果；若按清除16个频道提前结束，必须能列出16个互异频道的成功事件。程序结束前逐项检查20个频道状态，除合法的16源上限捷径外，不允许存在未发现未排除或已发现未清除频道。

## 11. 已明确不采用或尚不能成立的说法

- [x] 不采用“把所有可获得信息全部收集完再行动”。只收集完成任务或降低后续时间所需要的信息。
- [x] 不采用“每发现一个源，就立即前往第二问的单源最优第二检测点”。第二问只提供局部候选，下一目的地还要考虑路线和其他任务。
- [x] 不采用“每一步移动必须同时服务多个任务”作为硬约束。一点多用是优先偏好，必要的单目标移动仍然允许。
- [x] 不采用“所有检测坐标的 1000 m 圆总体覆盖目标区域，就能排除所有频道”。覆盖证据必须逐频道建立。
- [x] 不采用“最小外接圆半径小于 25 m 就保证一次清除”。严格的一次保证阈值是 20 m；25 m 只能作为尚待验证的尝试阈值。
- [x] 不采用“能被两个 20 m 圆覆盖就立即优先清除”。还必须计入机器狗从当前位置到清除区域以及清除点之间的移动时间。
- [x] 不采用“第二问最坏直径约 134 m，所以实际通常需要超过两次测向”。最坏情景不代表典型情景，实际第二次读数出来后应重新计算。
- [x] 不采用“定位区域直径等于最小外接圆直径”。只能使用一般关系 \(D\le 2R_{\mathrm{MEC}}\)，不能把两者视为相等。
- [x] 不采用“原地多次测向能够平均掉误差”。同一地点误差固定。
- [x] 当前基础版本不采用端到端神经网络或纯强化学习决定下一动作。
